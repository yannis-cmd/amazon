═══════════════════════════════════════════════════════════════════════════════
  2. QU'EST-CE QUE C'EST?
═══════════════════════════════════════════════════════════════════════════════

Un système COMPLET et PROFESSIONNEL de support client qui permet aux 
utilisateurs de:

  • Créer des tickets directement dans l'application
  • Recevoir des notifications partout (Discord, Telegram, Email, Sheets)
  • Consulter l'état de leurs tickets
  • Fonctionner COMPLÈTEMENT HORS LIGNE (stockage local)


═══════════════════════════════════════════════════════════════════════════════
  3. FONCTIONNALITÉS
═══════════════════════════════════════════════════════════════════════════════

CRÉATION DE TICKETS:
  • ID automatique unique (TKT-XXXXXXXX)
  • Email de l'utilisateur
  • Titre du problème
  • 5 catégories: bug | feature | crash | performance | other
  • 4 priorités: low | medium | high | critical
  • Description détaillée
  • Horodatage automatique

STOCKAGE LOCAL:
  • Base de données JSON (support_tickets.json)
  • Persiste sur le disque dur
  • Accessible même sans internet
  • Historique complet conservé

SYNCHRONISATION CLOUD (optionnel):
  • Discord Webhook → notifications en temps réel
  • Telegram Bot → notifications sur téléphone
  • Google Sheets → vue d'ensemble centralisée
  • Email SMTP → confirmations par email

SUIVI DES TICKETS:
  • Interface "Mes Tickets" pour l'utilisateur
  • Affiche: ID, titre, statut, priorité, catégorie, dates
  • Accessible directement depuis l'application
  • Mise à jour en temps réel

  5. CONFIGURATION CLOUD
═══════════════════════════════════════════════════════════════════════════════

SANS CONFIGURATION:
  → Tickets stockés localement dans support_tickets.json
  → Utilisateur voit "Mes Tickets"
  → Fonctionne IMMÉDIATEMENT, même hors ligne
  → Parfait pour démarrer rapidement

AVEC CONFIGURATION:
  Exécutez: python setup_support.py

  DISCORD (3 minutes)
    1. Créez un serveur Discord
    2. Webhook → Copiez l'URL
    3. Collez dans setup_support.py

  TELEGRAM (5 minutes)
    1. @BotFather → /newbot → Copiez token
    2. @userinfobot → Trouvez chat_id
    3. Entrez dans setup_support.py

  GOOGLE SHEETS (5 minutes)
    1. Créez un Google Sheet
    2. Google Cloud Console → Clé API
    3. Entrez dans setup_support.py

  EMAIL (3 minutes)
    1. Gmail → Mots de passe d'application
    2. Générez un mot de passe
    3. Entrez dans setup_support.py
