AMAZON TRACKER PRO
==================

Application tkinter pour tracker souris Amazon avec Assistant IA.

INSTALLATION RAPIDE:
====================
pip install -r requirements.txt
python amazon_tracker.py

UTILISATION:
============
- Tapez un budget (ex: "50") → IA recommande une souris
- Tapez "OUI" → Ouvre Amazon.fr
