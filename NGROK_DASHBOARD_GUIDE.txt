 📊 QU'EST-CE QUE C'EST?
═══════════════════════════════════════════════════════════════════════════════

C'est le **DASHBOARD D'INSPECTION NGROK**.

Il affiche:
  ✅ Toutes les requêtes HTTP/HTTPS
  ✅ Les réponses du serveur
  ✅ Headers & Body
  ✅ Statut codes (200, 404, 500, etc.)
  ✅ Temps de réponse
  ✅ Paramètres envoyés

En temps réel!

 🎯 COMMENT L'UTILISER
═══════════════════════════════════════════════════════════════════════════════

1. ACCÉDEZ AU DASHBOARD:
   http://127.0.0.1:4040/inspect/http

2. DANS VOTRE APP (https://abc123xyz.ngrok.io/):
   • Cherchez un article Amazon
   • Créez un ticket support
   • Consultez les logs
   • Cliquez sur les boutons

3. REGARDEZ LE DASHBOARD:
   Vous verrez toutes les requêtes en direct!

4. CLIQUEZ SUR UNE REQUÊTE:
   Vous verrez:
   • Méthode: GET / POST / etc.
   • URL: /api/search, /api/support, etc.
   • Status: 200 (OK), 400 (Erreur), etc.
   • Request body: Les données envoyées
   • Response body: La réponse du serveur
   • Headers: Cookies, types, etc.

 🐛 DÉBOGUER AVEC LE DASHBOARD
═══════════════════════════════════════════════════════════════════════════════

❌ "La recherche ne fonctionne pas"
   → Vérifiez dans le dashboard:
     • Status 200 ou 500?
     • Message d'erreur en Response?
     • Essayez "Replay"

   → Dashboard affiche:
     • POST /api/support 400 (erreur validation)
     • Vérifiez l'email en Request

   → Dashboard:
     • GET /api/logs 200 mais response vide?
     • Pas encore de logs créés?
