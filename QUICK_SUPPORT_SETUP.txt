📋 ÉTAPE 1: VÉRIFIER LES FICHIERS
═════════════════════════════════════════════════════════════════════════════

Assurez-vous que ces fichiers existent:
  ✓ support.py
  ✓ support_ui.py
  ✓ cloud_sync.py
  ✓ setup_support.py (optionnel)

Si un fichier manque, l'installation n'est pas complète.


🚀 ÉTAPE 2: CONFIGURATION MINIMALE (2 minutes)
═════════════════════════════════════════════════════════════════════════════

Rien à faire! Le système fonctionne avec la configuration par défaut.

Les tickets seront:
  ✓ Créés localement dans support_tickets.json
  ✓ Accessibles depuis "Mes Tickets"
  ✓ Sauvegardés automatiquement


☁️  ÉTAPE 3: CONFIGURATION CLOUD (Optionnel - 3 minutes)
═════════════════════════════════════════════════════════════════════════════

A. Configuration avec Interface Graphique (Recommandé)

   1. Exécutez: python setup_support.py
   2. Remplissez les informations
   3. Cliquez "Sauvegarder"

   C'est fait! cloud_config.json sera créé automatiquement.


B. Configuration Manuelle (Avancé)

   1. Copiez cloud_config.example.json → cloud_config.json
   2. Remplissez avec vos informations
   3. Sauvegardez


📱 SERVICES CLOUD DISPONIBLES
═════════════════════════════════════════════════════════════════════════════

DISCORD (⭐ Recommandé)
   - Notifications en temps réel
   - Interface riche avec couleurs
   - Gratuit
   - Étapes:
     1. Créez un serveur Discord
     2. Clic droit sur un canal → Paramètres → Intégrations → Webhooks
     3. Nouveau Webhook → Copiez l'URL
     4. Collez l'URL dans setup_support.py

TELEGRAM (⭐ Très Pratique)
   - Accès mobile
   - Notifications push
   - Gratuit
   - Étapes:
     1. Cherchez @BotFather dans Telegram
     2. /newbot → Suivez les instructions → Copiez le token
     3. Cherchez @userinfobot → Trouvez votre chat_id
     4. Entrez token et chat_id dans setup_support.py

GOOGLE SHEETS
   - Vue d'ensemble complète
   - Partage facile
   - Gratuit (avec Google Account)
   - Étapes:
     1. Créez un Google Sheet
     2. Google Cloud Console → Clé API
     3. Entrez Sheet ID et API Key dans setup_support.py

EMAIL
   - Simple
   - Universel
   - Gratuit (avec Gmail)
   - Étapes:
     1. Gmail → Paramètres → Mots de passe d'application
     2. Générez un mot de passe d'application
     3. Entrez credentials dans setup_support.py

🎯 UTILISATION FINALE
═════════════════════════════════════════════════════════════════════════════

1. L'utilisateur voit un bouton "Support Client" dans l'app
2. Clique sur le bouton
3. Fenêtre s'ouvre
4. Remplit un formulaire (titre, description, priorité)
5. Clique "Créer le Ticket"
6. Ticket créé et synchronisé vers tous les services configurés
7. Utilisateur reçoit la notification (Discord/Telegram/Email/etc)
8. Support peut consulter et répondre
9. Utilisateur consulte le statut depuis "Mes Tickets"

🐛 DÉPANNAGE RAPIDE
═════════════════════════════════════════════════════════════════════════════

Problème: Les tickets ne s'enregistrent pas
Solution: Vérifiez que vous avez les permissions d'écriture

Problème: Les notifications ne arrivent pas
Solution: Vérifiez cloud_config.json avec: python -c "from cloud_sync import cloud_sync; print(cloud_sync.config)"

Problème: Erreur d'import
Solution: cd vers le bon répertoire et assurez-vous que support.py existe

Problème: cloud_sync.py plante
Solution: Assurez-vous que requests est installé: pip install requests
