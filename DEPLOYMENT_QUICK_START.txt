 ❌ ÇA NE MARCHE PAS?
═══════════════════════════════════════════════════════════════════════════════

run_web.bat donne erreur:
  → Vérifiez que Python est installé
  → Essayez: python --version
  → Relancez le script

deploy_web ne trouve pas Ngrok:
  → Installez Ngrok: https://ngrok.com/download
  → Ou attendez que le script l'installe

L'URL ne s'ouvre pas:
  → Attendre 5-10 secondes après le lancement
  → Vérifier votre connexion Internet
  → Essayer un autre navigateur
