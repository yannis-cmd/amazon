FLUX D'UTILISATION:
===================

1. CRÉATION DE TICKET:
   Utilisateur clique "Support Client"
   ↓
   Fenêtre s'ouvre (support_ui.py)
   ↓
   Remplit formulaire:
     - Email
     - Titre
     - Catégorie
     - Priorité
     - Description
   ↓
   Clique "Créer le Ticket"
   ↓
   Ticket créé avec ID unique (TKT-XXXXXXXX)
   ↓
   Sauvegardé dans support_tickets.json
   ↓
   Synchronisé vers services cloud configurés:
     - Discord: Embed formaté
     - Telegram: Message texte
     - Google Sheets: Nouvelle ligne
     - Email: Confirmation

2. CONSULTATION:
   Utilisateur clique "Mes Tickets"
   ↓
   Fenêtre affiche tous ses tickets:
     - ID du ticket
     - Titre
     - Statut
     - Priorité
     - Catégorie
     - Dates

3. GESTION (Support Team):
   Édition manuelle du JSON ou API:
     - Ajouter des notes
     - Changer le statut
     - Ajouter des informations

   Utilisateur voit les changements
   quand il consulte "Mes Tickets"


FICHIERS GÉNÉRÉS À L'USAGE:
============================

support_tickets.json (base de données):
   Format JSON
   Contient tous les tickets créés
   Exemple:
   {
     "TKT-ABC123": {
       "ticket_id": "TKT-ABC123",
       "title": "Crash au démarrage",
       "description": "L'app crash immédiatement",
       "category": "crash",
       "priority": "critical",
       "status": "open",
       "user_email": "user@example.com",
       "created_at": "2026-01-19T10:30:00",
       "updated_at": "2026-01-19T10:30:00",
       "notes": ["[timestamp] Note 1", "[timestamp] Note 2"]
     }
   }

cloud_config.json (configuration):
   Créé par setup_support.py
   Contient webhooks, tokens, clés API
   À garder secret!
   Exemple:
   {
     "discord_webhook": "https://discordapp.com/api/webhooks/...",
     "telegram_bot_token": "123456:ABCdef...",
     "telegram_chat_id": "123456789",
     "google_sheet_id": "...",
     "google_api_key": "...",
     "smtp_server": "smtp.gmail.com",
     "smtp_port": 587,
     "from_email": "email@gmail.com",
     "from_password": "app-password"
   }

logs/amazon_tracker_*.log:
   Logs détaillés pour déboguer
   Enregistre les créations de tickets
   Enregistre les synchronisations

CONFIGURATION CLOUD (5 min chacun):
====================================

DISCORD:
   1. Créez un serveur Discord (ou utilisez un existant)
   2. Créez un canal (ex: #support-tickets)
   3. Clic droit → Paramètres → Intégrations → Webhooks
   4. Nouveau Webhook → Copiez l'URL
   5. Collez dans setup_support.py

TELEGRAM:
   1. Cherchez @BotFather dans Telegram
   2. /newbot → Suivez les instructions → Copiez le token
   3. Cherchez @userinfobot → Trouvez votre chat_id
   4. Entrez dans setup_support.py

GOOGLE SHEETS:
   1. Créez un Google Sheet
   2. Google Cloud Console → Projet → API Sheets
   3. Créez une clé API
   4. Entrez Sheet ID et clé dans setup_support.py

EMAIL:
   1. Gmail → Paramètres → Mots de passe d'application
   2. Générez un mot de passe spécifique pour l'app
   3. Entrez credentials dans setup_support.py
