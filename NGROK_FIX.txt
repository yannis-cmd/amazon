SOLUTION 2: CREER UN COMPTE NGROK GRATUIT (RECOMMANDE)
────────────────────────────────────────────────────────────────

1. Allez sur: https://ngrok.com/
   
2. Cliquez "Sign Up" (gratuit)
   
3. Verifiez votre email
   
4. Copiez votre AUTH TOKEN depuis le dashboard
   
5. Configurez le token en PowerShell:
   
   $env:NGROK_AUTHTOKEN='COPIEZ_VOTRE_TOKEN_ICI'
   
6. Lancez le tunnel:
   
   python ngrok_tunnel.py

7. Vous verrez:
   
   PUBLIC URL: https://xxxxx-xx-xxx.ngrok-free.app/

Avantages:
  ✅ Gratuit
  ✅ Acces depuis internet (partout)
  ✅ Facile a partager

Inconvenient:
  ❌ L'URL change a chaque redemarrage (plan gratuit)
  ✅ URL fixe disponible avec plan Pro (~5$/mois)
