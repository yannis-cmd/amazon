✅ POUR LES UTILISATEURS - Installation facile

  1. ANDROID
     • Téléchargez: amazon_tracker_mobile.apk
     • Installez sur votre téléphone
     • Ouvrez l'application
     ✓ C'est tout! 🎉

  2. iOS  
     • Téléchargez depuis l'App Store
     • Installez sur votre iPhone/iPad
     • Ouvrez l'application
     ✓ C'est tout! 🎉


⚙️ POUR LES DÉVELOPPEURS - Compilation personnalisée

  1. Vérifiez les prérequis:
     python build_mobile_app.py
  
  2. Compiler:
     bash install_mobile.sh  (Linux/macOS)
     install_mobile.bat      (Windows)
  
  3. Générez l'APK/IPA:
     buildozer android debug
     buildozer ios debug

🔧 DÉPANNAGE RAPIDE
───────────────────────────────────────────────────────────────────────────────

Problème: L'APK ne s'installe pas
→ Vérifiez que vous avez activé "Sources inconnues"
→ Consultez: MOBILE_INSTALLATION.md section Dépannage

Problème: Je ne peux pas compiler
→ Vérifiez les prérequis: python build_mobile_app.py
→ Consultez: MOBILE_INSTALLATION.md section Compilation avancée

Problème: L'application plante
→ Réinstallez l'application
→ Videz le cache
→ Consultez: MOBILE_INSTALLATION.md section Dépannage
