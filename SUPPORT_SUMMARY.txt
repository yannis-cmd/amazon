FONCTIONNALITÉS:
=================

1. CRÉATION DE TICKETS
   - Formulaire avec titre, description, catégorie, priorité
   - Email de l'utilisateur
   - Numéro ID automatique (TKT-XXXXXXXX)

2. CATÉGORIES
   - bug (rapport de bug)
   - feature (demande de fonctionnalité)
   - crash (application se ferme)
   - performance (lent ou lourd)
   - other (autre)

3. PRIORITÉS
   - low (amélioration mineure)
   - medium (bug standard)
   - high (bug affectant la fonction)
   - critical (application inutilisable)

4. STOCKAGE LOCAL
   - support_tickets.json (base de données locale)
   - Persiste sur le disque
   - Accessible hors ligne

5. NOTIFICATIONS CLOUD
   - Discord: Notifications richement formatées en temps réel
   - Telegram: Accès mobile et notifications push
   - Google Sheets: Vue d'ensemble et partage
   - Email: Confirmation et notifications

6. SUIVI
   - "Mes Tickets" pour voir ses tickets
   - Affiche statut, priorité, catégorie, dates
   - Accessible depuis l'application

7. STATUTS
   - open: Créé, en attente
   - in_progress: En cours de traitement
   - resolved: Problème résolu
   - closed: Ticket fermé

COMMENT L'UTILISER:
====================

ÉTAPE 1: Ajouter un bouton dans l'app (1 ligne)
   from support_ui import show_support_window
   support_button = tk.Button(..., command=lambda: show_support_window(root))

ÉTAPE 2: Configuration optionnelle (5 minutes)
   python setup_support.py
   
   Remplir:
   - Discord Webhook URL (optionnel)
   - Telegram Token et Chat ID (optionnel)
   - Google Sheets ID et API Key (optionnel)
   - Email SMTP (optionnel)

ÉTAPE 3: Utiliser
   - Utilisateur clique "Support"
   - Remplit formulaire
   - Clique "Créer le Ticket"
   - Ticket créé localement ET synchronisé vers services cloud
   - Utilisateur reçoit notifications partout
   - Peut consulter depuis "Mes Tickets"


CONFIGURATION CLOUD (5 minutes chacune):
=========================================

DISCORD:
   1. Créez un serveur Discord
   2. Clic droit sur un canal → Paramètres → Intégrations → Webhooks
   3. Nouveau Webhook → Copiez l'URL
   4. Collez dans setup_support.py

TELEGRAM:
   1. Cherchez @BotFather dans Telegram
   2. /newbot → Suivez les instructions → Copiez le token
   3. Cherchez @userinfobot → Trouvez votre chat_id
   4. Entrez dans setup_support.py

GOOGLE SHEETS:
   1. Créez un Google Sheet
   2. Google Cloud Console → Créez un projet → Activez API Sheets
   3. Créez une clé API
   4. Entrez dans setup_support.py

EMAIL:
   1. Gmail → Paramètres → Mots de passe d'application
   2. Générez un mot de passe d'application
   3. Entrez dans setup_support.py
